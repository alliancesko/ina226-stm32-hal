# История изменений

Английская версия: [CHANGELOG.md](CHANGELOG.md)

## 0.2.0 — 2026-11-09

### Исправления

- Current LSB и Power LSB пересчитываются по целому значению регистра Calibration, что устраняет ошибку масштаба из-за усечения.
- Calibration ограничивается по консервативной границе кода шунтового АЦП, предотвращая переполнение Current в заданном идеальном измерительном диапазоне. Смещение, ошибка усиления и шум датчика по-прежнему требуют запаса со стороны приложения.
- Перед преобразованием Calibration в целое число проверяются промежуточные float-значения и допустимость выходных коэффициентов. Производственный код использует только float-арифметику.
- Функции чтения тока и мощности проверяют OVF также при включённой защёлке ALERT.
- AFF и CVRF, полученные при чтении Mask/Enable, сохраняются программно, в том числе при прямом чтении регистра. Сохранённые флаги объединяют события, а не подсчитывают их.
- При запуске нового преобразования сбрасывается сохранённый CVRF старого цикла. AFF сохраняется при смене режима до получения статуса. Reset, DeInit и ошибки записи очищают сохранённые события.
- Любая ошибка записи и прямая запись Configuration/Calibration снимают признак инициализации. Для дальнейших высокоуровневых операций требуется повторный Init.
- При проверке присутствия устройства распознаётся HAL_ERROR с HAL_I2C_ERROR_TIMEOUT.
- Исключено переполнение счётчика опроса reset при увеличении числа попыток.

### Переносимость

- Добавлено необязательное определение INA226_HAL_HEADER для выбора HAL-заголовка при компиляции; по умолчанию используется main.h.
- В публичный заголовок явно подключён stdint.h.

### Совместимость

- Сигнатуры публичных функций сохранены.
- В INA226_Handle_t добавлено поле conversion_ready_pending. Необходима совместная пересборка приложения и драйвера; бинарная совместимость не сохраняется.
- Функции чтения тока и мощности теперь читают Mask/Enable и в режиме защёлки, подтверждая аппаратный ALERT и сохраняя события программно. INA226_Read по-прежнему выполняет четыре чтения измерений, не подтверждая ALERT и не проверяя OVF.
- Отказ Init при проверке параметров оставляет прежний handle и аппаратное состояние без изменений. Ошибка после начала I2C-последовательности инициализации оставляет handle неинициализированным.

### Проверки

- Выполнены регрессионные тесты Linux с имитацией HAL, UBSan, проверки границ калибровки, предупреждений GCC и статический анализ.
- Полностью линкованная Release-прошивка STM32G030F6P6 (-Os, ARM GCC 14.3): Flash 10624 → 10812 байт; статическая RAM не изменилась — 1720 байт. Результат зависит от приложения и компилятора; аппаратная проверка нового поведения ещё предстоит.

## 0.1.0 — 2026-09-29

- Первый публичный выпуск: блокирующий драйвер STM32 HAL I2C, отдельные handle для устройств, автоматическая калибровка, настраиваемые режимы преобразования и усреднение, поддержка ALERT, прямой доступ к регистрам, английская и русская документация.
